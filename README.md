# Ananta Logistics Website

Corporate website for Ananta Logistics, built with Next.js, TypeScript and Tailwind CSS.

## Languages

- English: `/en`
- Simplified Chinese: `/zh`
- Traditional Chinese: `/zh-hant`

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project uses Next.js static export and creates deployable files in `out/`.
